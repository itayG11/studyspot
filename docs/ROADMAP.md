# התוכנית עד הסוף: StudySpot

עדכון: 12 באוקטובר 2026. **זה המסמך היחיד שקובע את הסדר.** אם משהו כאן סותר את דוח הביקורת, המסמך הזה גובר.

**כללים לכל גל:**
- **טסט לפני קוד,** ואחר כך סוכני סקירת קוד ואבטחה.
- **בדיקה שגיטהאב ירוק** אחרי כל דחיפה. זה כלל חדש, אחרי הטעות שלי.
- **שמירה בגיט ודחיפה.** אחר כך עצירה וסיכום קצר, ואתה מאשר את הגל הבא.
- **כל אישור תקף לגל אחד בלבד.**

**שלושה דברים שיכולים להגיע בכל רגע, ונכנסים מיד כשהם מגיעים:**

| מה | מה קורה כשזה מגיע |
|---|---|
| הדומיין ו-`Brevo`, בערך ב-14 באוקטובר | גל 11 עובר לראש התור, אחרי הגל שבאמצע |
| קובץ התמונות ממך | התמונות נכנסות לגל 5 |
| אישור לימודים באנגלית | ההגשה ל-GitHub Education, ומשם הדומיין |
