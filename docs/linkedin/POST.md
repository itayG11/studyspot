# פוסט ללינקדאין: טיוטה

הפוסט מפורסם רק על ידי המשתמש. הסרטון מועלה ישירות ללינקדאין, מהקובץ מה-`Release`.

## עברית

יש לכם 50 דקות פנויות בין שני שיעורים. איפה תלמדו?

הספרייה אולי מלאה, אבל במעבדת מחשבים שנמצאת שתי דקות מכם יש מקום. הבעיה היא שצריך ללכת לשם כדי לגלות.

אז בניתי את StudySpot, אתר שמראה בזמן אמת אילו מקומות לימוד בקמפוס פנויים.

מה אפשר לעשות בו:
• לראות על מפה מה פנוי עכשיו ומה צפוי להתמלא
• להזין את מערכת השעות ולקבל הצעה למקום קרוב לשיעור הבא
• להזמין מקום ולהיכנס אליו בסריקת קוד. הזמנה שאף אחד לא הגיע אליה משתחררת לבד
• למוסדות יש מסך ליד הדלת, ווידג׳ט ו־API משלהם

חשוב לדעת: האתר חי, אבל הנתונים בהדגמה הם לדוגמה בלבד ולא מראים את התפוסה האמיתית בקמפוס.

זה פרויקט הווב המלא הראשון שלי, במקביל ללימודי שנה ב׳ בהנדסת תוכנה במכללת בראודה. בניתי אותו עם Claude ככלי עזר. את ההחלטות, הבדיקות והאבטחה אני עשיתי.

אפשר לנסות בעצמכם: https://getstudyspot.me/demo
הקוד ב־GitHub: https://github.com/itayG11/studyspot

מה הכי חשוב לכם כשאתם מחפשים מקום ללמוד: שקט, קרבה לשיעור הבא, או לדעת מראש שיש מקום פנוי?

## English

You have 50 free minutes between two classes. Where do you study?

The library may be full, but a computer lab two minutes away has space. The problem is that you have to walk there to find out.

So I built StudySpot, a web app that shows which study spaces on campus are free, in real time.

What it does:
• Shows on a map what is free now and what is about to fill up
• Takes your timetable and suggests a place near your next class
• Lets you book a spot and check in by scanning a code. A booking nobody shows up for is released automatically
• Gives institutions a screen by the door, a widget and an API

One thing to know: the site is live, but the data in the demo is sample data and does not show real occupancy on campus.

This is my first complete web project, built alongside my second year in software engineering at Braude College. I built it with Claude as a helper. The decisions, the testing and the security are mine.
